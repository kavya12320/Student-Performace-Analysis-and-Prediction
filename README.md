# Student Performance Analysis and Prediction System

## Project Overview

This project analyzes students' academic performance using Python
and Machine Learning.

It identifies patterns in student performance and predicts
expected final examination marks using Linear Regression.

## Objectives

- Analyze student academic performance.
- Clean and preprocess student data.
- Perform exploratory data analysis.
- Identify relationships between academic features.
- Predict final examination marks.
- Evaluate model performance.

## Dataset

The project uses the UCI Student Performance dataset.

Dataset source:
https://archive.ics.uci.edu/dataset/320/student+performance

The dataset contains student academic information, including
study time, previous examination marks, absences, and final marks.

## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Installation

Install the required libraries:

pip install -r requirements.txt

## Running the Project

Open the notebook:

notebooks/student_performance_analysis.ipynb

Run all cells in order.

## Machine Learning Model

The project uses Linear Regression to predict final examination marks.

## Evaluation Metrics

- Mean Absolute Error
- Root Mean Squared Error
- R2 Score

## Results

The notebook generates model evaluation results,
visualizations, and actual versus predicted marks.

## Limitations

The dataset contains limited academic information.
The model's predictions are estimates and may not represent
every student's actual performance.
